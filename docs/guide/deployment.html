Deployment

Docker, Kubernetes, Helm, static product site, and optional MCP for AI agents.

Local brokers (development)

docker compose -f docker/docker-compose.brokers.yml up -d
cd backend && mvn -pl eventore-server -am spring-boot:run -Dspring-boot.run.profiles=local
cd frontend && npm install && npm run dev

Production image

# All providers (default)
docker build -f docker/Dockerfile.backend -t eventore-backend .

# Kafka + Kinesis only
docker build --build-arg EVENTORE_MAVEN_PROFILES=kafka-kinesis \
  -f docker/Dockerfile.backend -t eventore-backend:slim .

Helm (recommended for K8s)

Chart deploy/helm/eventore deploys backend + frontend pods. Values files:

  • values.yaml — defaults
  • values-admin.yaml — full admin mode
  • values-kafka-kinesis.yaml — slim protocols
helm install eventore ./deploy/helm/eventore \
  --set ingress.enabled=true \
  --set ingress.hosts[0].host=eventore.example.com

# Slim stack
helm upgrade --install eventore ./deploy/helm/eventore \
  -f deploy/helm/eventore/values-kafka-kinesis.yaml

See deploy/README.md in the repository for ingress, secrets, and network policies.

Hosting this documentation site

The docs/ folder is the product site (HTML + CSS + SVG). It is intended for GitHub Pages:

# Repository Settings → Pages → Branch: main, Folder: /docs

# Local preview
npx serve docs

See docs/README.md for details. The .nojekyll file ensures GitHub serves static HTML without Jekyll processing.

MCP server (optional)

A separate Node MCP server (mcp/eventore-mcp) lets AI agents list connections, browse topics, and stream messages via tools. Deploy chart eventore-mcp when agents need programmatic access.

  • Point MCP at the backend base URL
  • Respect the same deployment mode and auth as the UI

Health and observability

GET /actuator/health
GET /api/v1/config
GET /api/v1/control/plane

Use control plane revision to detect provider registration changes without restarting the UI.
