GCP Pub/Sub

Google Cloud Pub/Sub topics, subscriptions, and message peek.

Wire protocol: GCP_PUBSUB. See Connections.

Connect

  • Google Cloud project ID
  • Service account JSON key path or Application Default Credentials (ADC)
  • Optional topic/subscription prefix filters

Browse & inspect

  • List topics and subscriptions in the project
  • Pull/peek messages for troubleshooting (respect ack deadlines)
  • Subscription backlog metrics where available

Live streaming

Stream pulled messages into the workspace with filters and export — Streaming & live view.

Administration

Topic and subscription IAM are managed in GCP. Eventore uses granted roles on the service account (e.g. pubsub.subscriber, pubsub.publisher).

Credentials

  • Service account JSON mounted as a secret in Kubernetes
  • Workload Identity on GKE recommended over long-lived keys
