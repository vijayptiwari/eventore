JMS

Apache Artemis, Amazon MQ (OpenWire), and JMS destinations.

Wire protocol: JMS. Preset: Amazon MQ. See Connections.

Connect

  • JNDI or broker URL for Artemis / ActiveMQ-compatible brokers
  • Queue and topic destination names
  • Credentials matching broker realm configuration

Browse & inspect

  • List queues and topics configured on the connection
  • Destination metadata and depth where the broker exposes management beans
  • Message browse via live view rather than heavy historical search

Live streaming

Attach JMS destinations to the live workspace for continuous consumption — Streaming & live view.

Administration

Destination creation and broker tuning are performed in Artemis/MQ admin tools; EventOre focuses on observe and publish test traffic in DEV/ADMIN modes.

Credentials

  • Amazon MQ — broker user from AWS console; TLS enforced on preset
  • Artemis — role-based users defined in broker.xml
