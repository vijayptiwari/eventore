EventOre in two minutes

Connect, inspect, and follow a message across brokers.

This illustrated walkthrough uses sample data. It is not connected to live brokers. Follow the linked labs to try the real product.

01 / Product tour

Connect your brokers

kafka:9092 → EventOre ← rabbitmq:5672

Create a named connection profile for each system. EventOre runs broker operations through its backend, so network reachability and credentials are configured there.

04 / Product tour

Deploy in your environment

Your infrastructure / versioned images / configurable access

Use versioned container images and Helm charts. Configure API authentication and persistence explicitly. Bridge state remains process-local; deployment modes do not replace broker authorization.
