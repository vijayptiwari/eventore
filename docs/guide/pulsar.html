Pulsar

Apache Pulsar tenants, namespaces, topics, subscriptions, and backlog inspection.

Wire protocol: PULSAR. See Connections.

Connect

  • Service URL for broker or proxy (pulsar:// or pulsar+ssl://)
  • Authentication token or TLS as required by the cluster

Browse & inspect

  • Topics and partitioned topics under tenants/namespaces
  • Subscriptions and backlog statistics where exposed by the broker
  • Reader-based message peek for troubleshooting

Live streaming

Live view subscribes to Pulsar topics in the shared workspace. Filters and export behave like other protocols — Streaming & live view.

Administration

Partial admin: namespace/topic operations supported where the provider implements them. Full cluster policy management may require Pulsar CLI or vendor tools.

Credentials

  • JWT or TLS client certificates common on managed Pulsar
  • Store secrets in connection properties; never commit credentials to git
