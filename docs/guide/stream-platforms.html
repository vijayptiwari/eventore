Cloud presets

GET /api/v1/platforms returns presets that set cloudProvider, streamPlatform, brokerUrl, and default properties:

  • AWS — MSK (Kafka), Kinesis, MQ (JMS), IoT Core (MQTT)
  • Azure — Event Hubs (Kafka), Service Bus, IoT Hub (MQTT)
  • GCP — Pub/Sub, Managed Kafka
  • OCP — AMQ Streams / Strimzi (Kafka)

  • Kafka cloud — SASL/SSL on preset; username/password or IAM

  • GCP Pub/Sub — service account JSON or ADC
  • Azure Service Bus — connection string or Entra ID
