RabbitMQ

Queues, exchanges, bindings, and management API integration.

Wire protocol: RABBITMQ (management plugin required). See Connections.

Connect

  • Management API base URL (typically port 15672)
  • AMQP host/port for messaging paths used by streaming
  • Username/password with management tag

Browse & inspect

  • Queues, exchanges, and bindings via management API
  • Queue depth and consumer utilization
  • Get/purge messages for supported operations (ADMIN mode)

Live streaming

Stream messages from bound queues into the live workspace. See Streaming & live view.

Administration

Queue purge and message get via management API where enabled. Topology changes (declare exchange/queue) depend on deployment mode and provider capabilities.

Credentials

  • Standard RabbitMQ user/password over TLS recommended for production
  • Restrict management access to operators; use READONLY Eventore profile for observers
