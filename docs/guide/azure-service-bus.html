Azure Service Bus

Queues, topics, subscriptions, and administration via Service Bus APIs.

Wire protocol: AZURE_SERVICE_BUS. See Connections.

Connect

  • Namespace hostname and entity path (queue or topic)
  • Connection string (dev) or Entra ID / managed identity (production)
  • Separate connections per queue/topic when isolating environments

Browse & inspect

  • List queues, topics, and subscriptions via admin API
  • Peek messages for diagnostics without removing from queue
  • Live view for active troubleshooting sessions

Live streaming

Receive/peek into the shared live workspace — Streaming & live view.

Administration

Entity create/delete and SAS policies are Azure portal/ARM tasks. EventOre focuses on operational visibility and test publish in ADMIN mode.

Credentials

  • Connection string — quick start; rotate frequently
  • Entra ID — app registration or managed identity with Azure Service Bus Data Owner/Receiver roles
