AWS Kinesis

Kinesis Data Streams — shards, iterators, and live record consumption.

Wire protocol: KINESIS. Preset: AWS Kinesis. See Connections.

Connect

  • Region and stream name (or discover streams after auth)
  • IAM access keys, assumed role, or instance profile via default credential chain
  • Slim deployments: build image with Kinesis provider only

Browse & inspect

  • List streams and shard iterators
  • Shard-level throughput and iterator position
  • Historical message search: planned; use live view for recent records

Live streaming

Poll or subscribe to shard iterators in the live workspace — Streaming & live view.

Administration

Stream creation and resharding are AWS console/CLI operations. Eventore does not replace Kinesis capacity planning tools.

Credentials

  • Access key + secret (dev only) or IAM role on EKS/EC2
  • Least privilege: kinesis:DescribeStream, GetRecords, PutRecord as needed
