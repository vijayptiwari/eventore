Inspection

Browse destinations, consumer groups, lag, and message search across registered protocols.

Browse

  1. Select a connection.
  2. Eventore lists destinations (topics, queues, streams, subscriptions).
  3. Open a destination to see partitions, metadata, or recent messages where supported.
  4. Use Add to streams to track it in the live workspace.

Only protocols in controlPlane.uiCascade.inspectProtocols show inspector features.

Kafka inspection

  • Topic list with partition count and replication
  • Consumer groups and per-partition lag
  • Message search by offset, timestamp, or key filter
GET /api/v1/connections/{id}/inspect/topics
GET /api/v1/connections/{id}/inspect/consumer-groups
GET /api/v1/connections/{id}/inspect/topics/{topic}/messages?limit=50
