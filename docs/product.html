One workspace. A modular system.

EventOre connects a React console to a Spring Boot backend with protocol-specific provider modules. The backend handles broker connections; the browser consumes the API and live message transports.

Interface

React + TypeScript

A shared workspace for connections, live streams, supported inspection tools, and message publishing.

Tour the console ↗
Runtime

Java 21 + Spring Boot

Provider modules for eight messaging protocols. Build only the providers your deployment needs.

Read the architecture ↗
Interfaces

OpenAPI, streams, MCP

REST APIs, WebSocket live views, SSE subscriptions, and an optional MCP service for agent integrations.

Workflows introduced in 0.2.1.

The published release introduced bridging, connection stores, Kafka topology and lag views, trace links, field masking, replay, DLQ redrive and schema-aware publishing. The unreleased audit fixes below improve these implementations.

Eight protocols, different capabilities.

Kafka, RabbitMQ, Pulsar, MQTT, JMS, Kinesis, GCP Pub/Sub, and Azure Service Bus share the console. Search, lag, and administration support vary by provider.

Foundations and fixes on main.

Development adds HS256 JWT identity validation, operation-level role enforcement, an in-memory workspace catalog, local subscription distribution and heuristic MCP incident triage. The October audit also fixes persistence safety, schema handling, bridge delivery and diagnostic reporting.

Review before building from source

These changes are unreleased. Read the development history for implementation details and the fixes that are absent from 0.2.1 artifacts.

Unreleased changes ↗

Current limits

No enterprise SSO, workspace tenant isolation or Redis cross-pod streaming. Workspaces are metadata; subscriptions remain process-local. Triage uses fixed heuristics and sampled diagnostics.
