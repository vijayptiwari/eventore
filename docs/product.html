One workspace. A modular system.

EventOre connects a React console to a Spring Boot backend with protocol-specific provider modules. The backend handles broker connections; the browser consumes the API and live message transports.

Interface

React + TypeScript

A shared workspace for connections, live streams, supported inspection tools, and message publishing.

Runtime

Java 21 + Spring Boot

Provider modules for eight messaging protocols. Build only the providers your deployment needs.

Understand what is available.

Eight protocols, different capabilities.

Kafka, RabbitMQ, Pulsar, MQTT, JMS, Kinesis, GCP Pub/Sub, and Azure Service Bus share the console. Search, lag, and administration support vary by provider.
