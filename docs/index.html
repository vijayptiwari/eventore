Before you begin

A few good questions.

What is EventOre?

EventOre is a self-hosted messaging and streaming console for Kafka, RabbitMQ, Pulsar, MQTT, JMS, AWS Kinesis, GCP Pub/Sub, and Azure Service Bus. It brings connections, live streams, and supported inspection tools into one workspace.

Does every protocol support every feature?

No. Browsing, historical search, administration, and lag inspection depend on the provider and broker permissions. The protocol capability guide explains the differences.

Does EventOre replace my message broker?

No. It connects to your existing brokers. You deploy the console and its backend in your environment, then configure connection profiles for the systems you already run.

How do I choose an access mode?

Admin enables administrative workflows. Dev supports development with publish size limits. ReadOnly disables publishing and connection changes. These are deployment modes; configure broker credentials and API authentication separately. See configuration.

Can I use it with AI agents?

The optional MCP server exposes tools backed by the EventOre API. Deploy and configure it separately when your agent needs access to supported broker operations.
