Frequently Asked Questions

Everything you need to know about deploying and operating Eventore.

What is Eventore and who is it built for?
Eventore is an enterprise-grade open-source multi-protocol streaming and messaging console that replaces fragmented single-broker UIs. It is built for platform engineers, SREs, and backend developers who manage messaging systems like Apache Kafka, RabbitMQ, Pulsar, MQTT, JMS, AWS Kinesis, GCP Pub/Sub, and Azure Service Bus.
How is Eventore different from Kafka UI or AKHQ?
While Kafka UI and AKHQ only support Apache Kafka, Eventore supports 8 messaging wire protocols in a single interface. Furthermore, Eventore includes capabilities not found in traditional tools: cross-broker replication bridges, real-time PII data masking to prevent compliance leaks, native W3C OpenTelemetry distributed tracing, visual partition lag heatmaps with skew alerts, and official Model Context Protocol (MCP) server support for AI agents.
How does Cross-Broker Data Replication work?
Eventore incorporates a reactive ReplicationBridgeEngine using Java Virtual Threads. You can define a bridge between any source connection (e.g., Kafka orders.v1) and any target connection (e.g., RabbitMQ warehouse.orders) with payload regex filters, header transformations, and loop prevention. An interactive dry-run API lets you verify transformations before starting production replication.
Can Eventore mask sensitive customer data (PII) in real-time?
Yes. Eventore's zero-copy Jackson AST DataMasker evaluates messages in memory before rendering in the browser or recording to audit logs. It supports full redaction, partial masking (e.g. preserving the first 4 and last 4 digits of a payment card), and salted SHA-256 hashing.
Does Eventore support OpenTelemetry distributed tracing?
Yes. Eventore natively inspects W3C TraceContext traceparent headers in every record. When inspecting messages or browsing live WebSocket streams, operators can click directly into Jaeger, Zipkin, Datadog, or Dynatrace to view the complete distributed flame graph for that transaction.
How do AI developer tools use Eventore via MCP?
Eventore provides a dedicated Model Context Protocol (MCP) server (eventore-mcp). AI development assistants like Cursor, Claude Desktop, and Gemini can connect to Eventore to query topic schemas, check consumer lag, inspect dead-letter queues, and publish test records safely using structured AI agent tools.
