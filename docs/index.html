Multi-stream messaging console

One console for every stream

Connect, browse, live-stream, inspect, and administer messaging systems from a single UI — with a modular control plane and slim deployments that include only the protocols you need.

Get started Architecture About

Built for operators and developers

From local debugging to production Kubernetes — one UI for every messaging backend you run.

Multi-protocol

Kafka, Pulsar, RabbitMQ, MQTT, JMS, AWS Kinesis, GCP Pub/Sub, and Azure Service Bus — with cloud presets for MSK, Event Hubs, IoT Core, and more.

Control & data plane

Register only the stream providers you deploy. The UI cascades capabilities from the control plane; the data plane handles all broker I/O.

Live view & export

Multi-topic WebSocket streaming with header/body regex filters, timed windows, and JSON, CSV, or NDJSON export.

Per-stream guides

Dedicated docs for Kafka, Pulsar, RabbitMQ, MQTT, JMS, Kinesis, GCP Pub/Sub, and Azure Service Bus — connect, inspect, live view, and admin in one place per protocol.

Production deployment

ADMIN, DEV, and READONLY profiles; GHCR images, OCI Helm charts, ingress, network policies, and slim protocol builds.

MCP for agents

Optional MCP server exposes control and data plane APIs to AI tools — probe brokers, publish, and inspect without the UI.

Product documentation

Step-by-step guides, configuration reference, architecture diagrams, and deployment examples.
