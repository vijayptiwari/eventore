Unreleased · 0.3.0

Implementation dates appear beside each milestone. No publication date is assigned to these changes.

2026-10-06Unreleased · 0.3.0

October audit: safer operations and more reliable diagnostics

Authentication and operation permissions

JWT signatures and expiration are required. Role matching and deployment-mode permissions cover REST and WebSocket operations; workspace resource isolation remains unfinished.

Read the guide · Implementation b147529

Connection persistence safety

Failed writes preserve live state; migration settings, optimistic versions, missing JDBC configuration and CRD resource-name collisions are handled explicitly.

Read the guide · Implementation b147529

Schemas, replay and bridge delivery

Registry caches are isolated, remote errors remain visible, binary Avro round-trips correctly, replay failures surface, and bridge delivery preserves provenance headers.

Read the guide · Implementation b147529

Honest diagnostic results

MCP handles backend lag and DLQ responses correctly, reports failed checks and returns UNKNOWN for incomplete clean assessments. DLQ counts are samples, not queue depth. The console reports partial redrive and absent lag data.

Read the guide · Implementation b147529

Release and cluster safeguards

Published version claims now follow verified release metadata. Unimplemented Redis distribution is rejected rather than appearing to provide cross-pod delivery.

Read the guide · Implementation 9e5155f
2026-10-06Unreleased · 0.3.0

Identity, workspace and cluster foundations; incident triage preview

HS256 JWT authentication foundation

Development implementation validates shared-secret JWTs and extracts identity claims. OIDC discovery, JWKS and enterprise sign-in are not implemented.

Read the guide · Implementation b387f2a

Workspace catalog and selector

In-memory workspace metadata and a browser selector. Connections, bridges and streams are not isolated by workspace; this is not a tenant security boundary.

Read the guide · Implementation b387f2a

Local subscription distribution interface

Local fan-out and node status are implemented. Redis mode is rejected at startup because its transport and shared subscription registry are unfinished.

Read the guide · Implementation b387f2a

Incident triage MCP preview

A compound diagnostic tool and prompt collect broker, lag and DLQ information using fixed heuristics. This preview offers investigation hints, not autonomous remediation.

Read the guide · Implementation b387f2a

Replication routing and connection feedback

Replication workflow fixes

Corrected replication routing and error handling, improved the empty-connection experience, and added schema and replay guides.

2026-10-04Introduced in 0.2.1

Connect systems. Keep connection state.

Cross-broker bridging

Route messages between brokers with filtering, header transformations, loop prevention, and a dry-run tester.

Read the guide · Implementation ed337a2

Externalized connection stores

File and JDBC stores plus a CRD-shaped resource-file store, with migration controls. The CRD implementation does not watch the Kubernetes API. Shared connection persistence does not distribute live subscriptions.
